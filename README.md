# 🔐 SHA-256 Hash Generator & Lookup Tool
[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/I0P0254E82)
![Project Banner](banner.jpg)

A lightweight, beginner-friendly command-line tool designed to generate SHA-256 cryptographic hashes and demonstrate how hash verification works. Built as a fun exploration into cryptography, data integrity, and cybersecurity fundamentals.

> **Note:** Technically, SHA-256 is a one-way cryptographic hashing algorithm rather than two-way encryption. While hashes cannot be mathematically "decrypted," this tool helps you generate hashes and compare or verify them against plain-text inputs.

---

## ✨ Features

* **Fast SHA-256 Hashing:** Instantly convert any text string or input into a secure 64-character hexadecimal SHA-256 hash.
* **Hash Verification:** Compare plain-text strings against existing SHA-256 hashes to verify data integrity.
* **Lightweight & Simple:** Zero bloat—easy to read, modify, and run for anyone learning cryptography or programming.
